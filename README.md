# FullStack RAG + VectorDB Demo (Spring Boot + React + Ollama)

This folder contains two separate project repositories:
- `backend` - Spring Boot RAG API
- `frontend` - React dashboard

Both are designed to run locally with Ollama.

## Project Layout

```text
RAG-VectorDB/
  backend/   # Spring Boot backend APIs and RAG pipeline
  frontend/  # React dashboard to visualize ingestion/retrieval/answering
```

## Quick Start

1. Start Ollama:
   ```bash
   ollama serve
   ```
2. Pull required models:
   ```bash
   ollama pull llama3.2
   ollama pull nomic-embed-text
   ```
3. Start backend:
   ```bash
   cd backend
   mvn spring-boot:run
   ```
4. Start frontend in another terminal:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
5. Open dashboard:
   - [http://localhost:5173](http://localhost:5173)

## End-to-End Working Example

1. Dashboard already includes seeded knowledge (`RAG Basics`, `Vector Database Concepts`).
2. Ask:
   - `How does retrieval improve LLM answers?`
3. Observe:
   - retrieved chunks with similarity score
   - grounded prompt built from retrieved chunks
   - final answer generated by Ollama

Then ingest your own text and repeat.
